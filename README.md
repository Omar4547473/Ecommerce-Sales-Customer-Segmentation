# 🛒 E-Commerce Sales & Customer Segmentation Analysis (End-to-End Project)

## 📌 Project Overview
This end-to-end data analytics project analyzes over **1 million real-world retail transactions** from a UK-based online retail store (Online Retail II dataset). The goal is to clean raw transactional data, uncover key business metrics, segment customers based on purchasing behavior, and build an interactive executive dashboard to drive strategic business decisions.

---

## 🛠️ Tools & Technologies Used
* **Database & Data Cleaning:** SQL Server (SSMS) — Data Import, Data Profiling, Filtering, Aggregations, and View/Table Creation.
* **Data Analysis & Visualization:** Python (Jupyter Notebook) — `pyodbc`, `pandas`, `numpy`, `matplotlib`, and `seaborn`.
* **Business Intelligence & Reporting:** Microsoft Power BI — Data Modeling (`One-to-Many` Relationship), DAX Measures, Interactive Slicers, and Dashboard Design.

---

## 🔄 Project Workflow

### 1. Data Exploration & Cleaning (SQL Server)
* Imported **1,067,371 raw rows** into SQL Server Management Studio.
* Identified and resolved major data quality issues:
  * Removed **19,494 cancelled invoices** (starting with `'C'`).
  * Filtered out invalid transactions with **zero/negative quantities (22,950 rows)** and **zero/negative prices (6,225 rows)**.
  * Excluded **243,007 rows** with missing `Customer_ID` values to ensure accurate customer-level analysis.
* Created a clean analytical table (`clean_retail_data`) with a calculated `Total_Revenue` column (`Quantity * Price`), resulting in **805,531 valid product transactions**.

### 2. Deep-Dive Analysis & Customer Segmentation (Python)
* Connected Python directly to SQL Server using `pyodbc` and loaded the cleaned dataset into a `pandas` DataFrame.
* Removed non-product stock codes (such as `'POST'`, `'M'`, `'DOT'`, `'BANK CHARGES'`, and `'ADJUST'`) to focus purely on physical merchandise.
* Conducted **FM (Frequency & Monetary) Analysis** across **5,853 unique customers**:
  * **Frequency:** Count of distinct invoices per customer.
  * **Monetary:** Total revenue generated by each customer.
* Segmented customers into three tiers (**Silver**, **Gold**, and **VIP**) using `pd.qcut()`.
* Built statistical visualizations using `seaborn` and `matplotlib` to examine customer distribution and top international markets.

### 3. Interactive Dashboarding (Power BI)
* Exported the cleaned transactional data and customer segmentation tables to Power BI.
* Established a **One-to-Many relationship** via `Customer_ID` in the Data Model.
* Designed an executive single-page dashboard featuring:
  * **4 Main KPI Cards:** Total Revenue (**£17.45M**), Total Customers (**5.85K**), Total Quantity (**11M**), and Total Orders (**36.62K**).
  * **Revenue by Customer Segment:** Donut chart highlighting the massive revenue contribution of the VIP tier (**86.89%**).
  * **Top 10 Countries & Top 10 Products:** Dynamic visuals filtered using `Top N`.
  * **Interactive Slicers:** Tile and dropdown filters for `Segment`, `Country`, and `Description`.

---

## 💡 Key Business Insights & Recommendations
1. **Pareto Principle in Action (VIP Dominance):** The **VIP customer segment** generates **£15.16M (86.89%)** of total revenue. **Recommendation:** Implement a dedicated VIP loyalty program and account management to maximize retention.
2. **Strong European Expansion Potential:** While the United Kingdom is the primary market (**£14.63M**), **Ireland (EIRE - £600.66K)**, **Netherlands (£549.95K)**, **Germany (£388.83K)**, and **France (£315.66K)** represent strong international hubs. **Recommendation:** Optimize shipping rates and run targeted marketing campaigns in Western Europe.
3. **High-Performing Core Products:** Items like *Regency Cakestand 3 Tier* and *White Hanging Heart T-Light Holder* consistently drive high revenue and volume. **Recommendation:** Ensure year-round inventory availability and bundle these bestsellers with slower-moving items.

## 🚀 How to Run This Project
1. Execute the SQL scripts in the `/SQL` folder to clean the raw dataset and create `clean_retail_data`.
2. Update the `SERVER` and `DATABASE` variables in the Jupyter Notebook (`customer_segmentation_analysis.ipynb`) and run all cells to generate the segmented customer data.
3. Open the `.pbix` file in Power BI Desktop to interact with the dashboard.
